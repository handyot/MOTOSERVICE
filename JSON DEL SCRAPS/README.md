# MOTOSERVICE — Repositorio Local de Archivos de Scraping

Esta carpeta contiene los archivos de scraping manual (CSV y JSON) utilizados como entrada para el importador de catálogos de MOTOSERVICE.

Marcas soportadas:
- TAILG
- GreenLine
- YADEA
- Kayencorp

> [!NOTE]
> Los archivos de datos descargados (`.csv`, `.json`) están excluidos del control de versiones por `.gitignore` para no saturar el repositorio y mantener seguros los extractos brutos originales.
